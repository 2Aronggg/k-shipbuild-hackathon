# WeldScan AI — 관리자용 판정 관제 대시보드

용접부 비파괴검사(RT/VT)에서 **검사자들의 판정 눈금이 얼마나 벌어져 있는지** 보는 품질관리 화면.

결함을 찾아주는 화면이 아님. 합격·불합격은 선급 규정표가 기계적으로 정하므로 사람 의견이 개입할 자리가 없고, 그 고정된 기준 위에 실제 판정을 겹치면 조직의 판정 산포가 직접 드러남. 이 대시보드가 측정하는 대상은 불량률이 아니라 **판정 일관성**임.

> 기획안 대비 변경된 설계 판단은 [`docs/design-decisions.md`](docs/design-decisions.md) 참조.

## 핵심 개념 — 규정 마진

화면의 거의 모든 숫자가 이 값 하나 위에 서 있음.

```
마진 = 허용 한계 대비 실제 결함 크기        1.0 이 합격선

RT 제1종 (기공)        max(결함점수합 / 점수상한,  최대결함크기 / 크기상한)
RT 제2종 (슬래그·융합)  합계길이 / 길이상한
VT                    결함치수 / 외관검사 허용치
RT 제3종 (균열)        크기 무관 전건 불합격
```

상한은 **모재두께**가 정함. 두께 20 mm 판에서 허용 지름이 5.0 mm인데 6.0 mm 기공이 나오면 마진 1.2 — 불합격.

이 값에는 난수도 모델 확신도도 들어가지 않음. 두께와 결함 치수만으로 결정되므로 누가 계산해도 같은 숫자가 나옴.

## 데이터

### 실측

| 출처 | 규모 | 용도 |
|---|---|---|
| 한국선급 강선규칙 제2편 적용지침 부록 2-7 7항 | 합격기준 5종 | 마진·등급 계산 |
| 동 규정 조문 벡터DB | 244청크 | 근거 조항 검색 |
| AI Hub 용접 AI 학습 데이터 (RT·일반강재) | 54,053장 | 결함 치수 실측 |
| 탐지 모델 평가 결과 | held-out 5,350장 | 검출률·오탐률 |

AI Hub 라벨에서 추출한 결함 폴리곤은 총 217,231개이며, 대시보드는 10% 표본 12,067행을 사용함.

**결함 폴리곤 → 긴지름 → 마진** 경로가 실측으로 도는 유일한 구간임.

### 합성

판정 이력 1,446건 / 90일 / 검사자 13명.

공개 데이터에는 *"누가 언제 어떻게 판정했고 이견이 있었는지"*가 없음. 그런데 이 대시보드가 측정하려는 대상이 바로 그것이므로, 없으면 화면 자체가 성립하지 않음.

```
규정 일치율     87.4%  (불일치 182건 — 과잉 엄격 105 · 누락 77)
에스컬레이션    66.6%
판독 평균       246초 (4.1분)
모재두께        4.0 ~ 55.0 mm · 중앙 16.8
```

합성한 것은 **사람의 판정 확률 모델 하나**뿐임. 규정 계산은 난수 없이 규정표를 그대로 적용하며, 결함 클래스 비율은 AI Hub 실제 분포와 소수점까지 일치함(최대 오차 0.04%p).

생성 규칙은 `gen2.py` 345줄에 전부 공개되어 있고 시드가 고정되어 있어 재현 가능함.

### 계산 경로가 둘인 이유

| | 합성 이력 | 실측 치수 |
|---|---|---|
| 두께 | 건별로 보유 | **없음** |
| 마진 계산 시점 | 생성 시점에 미리 | 브라우저에서 실시간 |
| 슬라이더 반응 | 없음 | 있음 |

실측 라벨에는 모재두께가 없으므로 `09` 패널의 슬라이더 값을 12,067행 전체에 적용해 런타임에 계산함. 따라서 슬라이더를 움직이면 `01`과 `09`만 다시 그려짐. 정상 동작임.

## 재생성

### 합성 판정 이력

```bash
python3 gen2.py
# → data2.json
```

`clauses.json`과 `kr_reg_vectordb/tables/kr_appx2-7_rt_tables.json`이 필요함. 경로는 스크립트 상단에서 수정.

### 실측 치수 페이로드

```bash
# 라벨 JSON에서 (가중치 불필요)
python3 connect_yolo.py from-labels \
  --labels "02.라벨링데이터/TL_RTST_결함_2. 기공" ... \
  --out real_labels.json

# 학습 가중치로 추론 후 (best.pt 확보 시)
python3 connect_yolo.py detect \
  --artifacts ./porosity_yolov8seg --images ./films \
  --src weldscan_porosity/src --spacing 0.1 --thickness 20 \
  --out real_labels.json
```

산출된 JSON을 HTML의 `const REAL = {...}` 자리에 교체하면 됨.

`connect_yolo.py`는 검출기 출력에서 **긴지름**을 직접 계산함. 검출기 문서가 안내하는 등가지름을 그대로 사용하면 결함이 약 24% 작게 들어가 판정의 10.3%가 뒤집히므로, 이 경로를 우회하는 것이 이 모듈의 역할임. 등가지름 경로였을 때의 결과도 함께 계산해 `audit_equivalent_diameter.flipped`로 표시함.

## 알려진 한계

### 필름 배율(pixel_spacing) 복원 불가

규정은 밀리미터, 라벨은 픽셀 단위이나 두 단위를 잇는 값이 데이터셋에 없음. 구축활용가이드 확인 결과 원천데이터는 필름 스캔 후 **결함 부위를 임의 배율로 확대**해 생성되었으며 배율이 기록되지 않음. 원본 해상도가 682종으로 분산된 것이 그 결과임.

현재 0.10 mm/px를 가정값으로 사용하되 슬라이더로 노출해 민감도를 표시함. 현장 도입 시 RT 장비 사양에서 확보되며 확대 처리가 없으므로 이 한계는 소멸함.

### 등급 경계가 잠정값

합격선(마진 1.0)은 KR 규정 원문이므로 확정값이나, 1~4급 경계는 KS B 0845 원문 미확보로 선급 허용 한계의 1/2·2배로 잠정 설정함.

### VT 언더컷 판정 제외

라벨에 길이만 있고 외관검사 기준이 요구하는 깊이가 없어 12,067행 중 1,098행(9.1%)을 판정에서 제외함. 화면에 명시됨.

### 결함 윤곽 정확도

탐지 모델의 이미지 단위 성능(검출률 0.83 / 정확도 0.97)은 양호하나 결함 단위 마스크 품질(mAP50 0.363 / mAP50-95 0.118)은 낮음. 대시보드가 요구하는 것은 후자이므로, 현 수준에서는 *"기공이 있다"*는 신뢰 가능하되 *"그 기공이 6.2 mm다"*는 검증이 필요함.
